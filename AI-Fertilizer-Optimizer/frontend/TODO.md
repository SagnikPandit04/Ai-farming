# FarmShield - Livestock Biosecurity Portal

## Project Overview
A web-based application for livestock biosecurity management with features including:
- Dashboard with biosecurity score tracking
- Risk assessment tools
- Alert management system
- Task tracking
- Fertilizer recommendations
- Digital record keeping
